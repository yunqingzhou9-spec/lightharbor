# 拾光 · LightHarbor

把拍下的时光，好好收起来。

在本机整理照片与延时摄影：可以整批导入，也可以一张张挑选，再按拍摄日期归档。复制保留来源原件，照片不上传，无需云端账号。

### Mac 安装

解压 ZIP，将 `拾光.app` 拖入“应用程序”，双击打开。建议放在本机应用目录，避免使用云同步目录。

Mac 版尚未做 Developer ID 签名或 Apple 公证，首次打开可能被系统安全机制拦截。Apple 芯片 Mac 已验证运行，Intel 仅核对通用架构，未实机验证。

> Mac ZIP 内保留了一份旧版“先读我.txt”。1.6.1 的功能、默认规则与验证范围以本 README 和对应发布页为准。

### Windows 启动

1. 将 ZIP **完整解压**到本机文件夹。
2. 双击 `Start-LightHarbor.cmd`，等待应用窗口打开。
3. 保留后台命令窗口，通过拾光窗口正常退出；处理照片时不要直接关闭后台命令窗口。

无需另装 Python 或管理员权限。系统需要 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) 和 [.NET Framework 4.8](https://dotnet.microsoft.com/download/dotnet-framework/net48)，缺失时请从微软官方安装。

**Windows 是便携预览版，尚未在 Windows 实机验证，也不是已签名安装器。** 不提供 Windows ARM 原生包。首次使用请先用临时素材验证流程。

## 1.6.1 可以做什么

- **整批保存，或慢慢挑选。** 扫描后直接进入照片浏览，按日期、类型和搜索结果查看；支持跨日期选择。
- **多个来源一起整理。** 可添加多个存储卡或照片文件夹，父子目录只扫描一次；同名照片按实际来源隔离配对。
- **关联 RAW 与 JPG。** RAW + JPG 按一次拍摄浏览，可复制两者、仅 JPG 或仅 RAW，并保留可靠关联的 XMP / AAE。
- **识别延时摄影。** 根据拍摄间隔识别序列，含延时照片的日期带图标；可逐张修正照片类型，并撤销本次修正。 - **看大图再决定。** 居中照片、右侧信息、双击缩放与拖动，底部选片和翻页操作保持可见。
- **确认去向后复制。** 核对目标文件夹、文件数量与格式；已有副本要求明确选择跳过或再复制，不覆盖旧文件。
- **一批完成，继续下一批。** 全部成功后自动清空本批选择，保留浏览条件和类型修正，直接继续挑选；支持整理记录、任务恢复和失败后重新核对。

照片按年和拍摄日期归档；延时序列与视频独立处理。JPG / RAW 可分开存放，当天只有一种类型时省略不必要的类型目录。已有归档结构保留，不搬动历史文件。

## 开始整理

1. **选择来源和保存位置。** 来源可选多个；保存位置须独立，不能与任何来源相同或互相包含。Mac 直接打开系统文件夹窗口，Windows 打开带缩略图的目录选择窗口。
2. **开始扫描。** 读取过程中显示实际数量和阶段；总量未知时不显示估算百分比，只有成功结束才显示“扫描完成 · 100%”。扫描可停止，停止后需重新扫描。
3. **选择要保留的照片。** 新任务不自动全选。可以选择全部，也可以按日期或逐张勾选。切换日期、类型或搜索条件只改变浏览范围，跨日期选择会保留。
4. **预览复制清单。** 在底部选择 JPG + RAW、仅 JPG 或仅 RAW，再核对保存去向和重复处理规则。只复制一种格式时，缺少该格式的拍摄会跳过并提示。
5. **确认复制。** 普通复制保留来源原件。全部成功后可直接选择下一批；暂停、停止、失败与重试按实际状态显示，恢复任务需重新核对并确认。

增删来源后需要重新扫描；未变化照片的选择与类型修正会保留。侧栏全选覆盖全部日期，照片区的范围选择按当前日期、分类和搜索结果生效，包括尚未加载的分页。

### 已有文件怎么处理

新任务默认**按文件名检查**，也可在整理设置中选择**内容核对**。恢复旧任务时保留该任务原来的规则；更改当前任务的核对方式需要重新扫描。

同名不代表内容相同。发现匹配文件时，需要明确选择“跳过匹配文件”或“全部再复制一份”；再复制会使用安全编号保留已有文件。复制格式决定要复制哪些原文件，不做 JPG / RAW 格式转换。

## 大图预览

列表缩略图与大图的低清 / 高清选择**互不联动**。第一次打开大图默认低清，本次应用会话内记住大图的选择；把列表切成高清不会自动改变大图。

| 操作 | 方法 |
| --- | --- |
| 选中 / 取消当前照片 | 底部选择按钮，或按空格；不会自动翻到下一张 |
| 查看上一张 / 下一张 | 翻页按钮，或左右方向键 |
| 放大 / 恢复适合窗口 | 双击照片，或使用缩放控件 |
| 查看放大后的局部 | 拖动照片 |
| 查看文件、日期和关联信息 | 顶部照片信息按钮，在右侧展开 |
| 关闭大图 | 关闭按钮，或按 Esc；有菜单展开时先收起菜单 |

RAW 预览会显示可用来源和实际尺寸；高清受原文件内嵌预览或解码能力限制，不会把低分辨率图放大后冒充高清。不同相机与格式支持有差异，预览失败不代表原件不能扫描或复制。

延时识别默认至少 30 次拍摄、20% 间隔容差，RAW + JPG 算一次，可在设置中调整。拍摄时间不可靠时会提示并使用修改日期；识别结果仍需人工检查。

## 清理照片

清理是独立流程，**只针对一个来源文件夹**。可直接清理，也可选择“核对备份后清理”；后者要求另一磁盘卷上有内容一致的备份。

先扫描并选择，再核对清理范围。最终确认会**永久删除所选照片及可靠关联文件，不经过废纸篓**；取消确认会保留选择。视频和未关联文件不纳入照片清理，复制格式选项也不会扩大删除范围。

恢复清理任务不会恢复旧的删除授权，必须重新选择并核对。删除日志保存在任务目录旁的 `cleanup-logs`。

## 关闭窗口与退出

**Mac：** 左上角关闭按钮只关闭窗口，后台继续处理；再次激活应用恢复原页面。使用 `⌘Q`、应用菜单或 Dock 的“退出”才会安全停止处理并结束应用，无额外退出确认。

**Windows：** 通过应用窗口正常退出；处理期间会请求退出确认并等待安全停止。不要直接关闭后台命令窗口。

## 本机记录与隐私

照片与预览均在本机处理，不上传照片，不调用收费 AI 接口。应用仅监听 `127.0.0.1`，操作使用随机令牌与当前任务身份校验。

- Mac 任务目录：`~/Library/Application Support/LightHarbor/tasks`
- Windows 任务目录：`%LOCALAPPDATA%\LightHarbor\tasks`

正常停止会保留已完成的副本，并清理未完成副本。断电或强制结束后请核对实际结果。反馈问题时请遮挡个人路径、照片、GPS 及含令牌的启动地址。

## 验证范围

Mac 1.6.1 已完成 Apple 芯片本机启动、浏览器与 Mac WebKit 流程、针对性测试、独立行为验证和审查，以及安装包与源码对应核验。

Windows 1.6.1 已核对固定依赖、包内文件哈希、x64 Python 运行时和扩展、源码及打包后的界面。解包源码的单元测试、生成素材扫描复制、目录选择接口与浏览器检查在 **Mac 主机**上完成，不能替代 Windows 原生验证。WebView2 / .NET、Windows 磁盘卷与权限、共享路径、原生窗口及不同相机 RAW 格式仍需实机试用。Windows 不支持 Apple Vision 景物识别。

测试仅使用生成素材。完整回归仍有 **4 项历史日期假设失败**，不声称全套通过；Intel Mac 与 Windows 实机验证、公证或正式代码签名均不在已完成范围内。
