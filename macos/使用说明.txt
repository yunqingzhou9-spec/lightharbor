拾光 · LightHarbor 1.3.4
让底片，回到各自的位置。

支持：macOS 13 Ventura 及以上，Apple 芯片和 Intel 处理器。
已包含运行环境，无需安装 Python、Xcode 或其他开发工具。

安装与打开
1. 解压 ZIP，把“拾光.app”放入 Applications 或你喜欢的工具文件夹。
2. 双击拾光，在独立窗口中操作，无需打开浏览器或 Codex。
3. 支持调整窗口、原生文件夹选择和 ⌘C / ⌘V。界面异常时可按 ⌘R 重新载入。

首次打开的系统提示
本版本使用本地临时签名，尚未获得 Apple Developer ID 签名和公证。
macOS 可能阻止首次打开。请先确认文件来自你信任的本地构建或本项目官方 GitHub Release；
如你信任该来源，可按 macOS 的提示在“系统设置 → 隐私与安全性”中选择“仍要打开”。
无需关闭系统安全保护。单位管理的电脑可能不允许未公证的应用。
项目：https://github.com/yunqingzhou9-spec/lightharbor

整理照片
1. 选择来源文件夹和独立的保存位置。目标不能位于来源里面，也不能反过来包含来源。
2. 点击“扫描，生成预览”。这一步不复制或创建归档目录。
3. 浏览日期、地点、景物和延时组；按需改名、移动归属、合并、拆分或排除。
4. 点击“下一步：检查并确认”，核对计划后再点击“确认无误，开始复制”。
5. 原件保持不变；副本校验完成后，结果页显示整理记录位置。

常见说明
• 延时检测基于拍摄时间间隔，是辅助判断，需要你预览确认。
• RAW/JPEG 同一次拍摄关联选择，实际放入各自的格式子文件夹。
• 日期的延时图标后数字表示组数；悬停可看待确认数量。
• 景物识别在 Mac 本地运行。位置来自照片 GPS 坐标分区，不是在线地名查询。
• 相机 RAW 支持取决于 macOS 解码能力；无法预览时原文件仍可复制。
• 关闭窗口时会提示退出。退出应用会安全停止当前工作并保存已生成的整理计划；
  已完成副本保留，原件不受影响。强制结束程序或断电不能保证清理未完成副本。
• 计划只保存在本机，在“恢复之前的整理任务”中选取。恢复时接回原存储卡和目标磁盘。
• 只监听本机地址，不上传照片，不调用收费 AI 接口。启动页面的地址不要发给别人。

版本与反馈
问题反馈：https://github.com/yunqingzhou9-spec/lightharbor/issues
反馈时请先遮挡个人路径、照片内容和精确定位；不要贴启动地址中的访问令牌。

1.2.0：复制范围与任务恢复
• 默认全复制；“选择要复制的文件夹”支持多选上级日期或拍摄组。
• 勾选照片后点“复制所选照片”；继续选其他照片可“加入本次复制清单”。关联 RAW / JPEG / XMP 一起纳入，格式仍分开存放。点击“恢复全复制”取消范围限制。
• 搜索、筛选、左侧合并拍摄组的勾选不改变复制范围。范围数量在预览顶部显示。
• 默认在所选目标目录及其子目录按文件名（含扩展名）快速查重，不读取照片内容。同名不保证内容一致；可在更多设置中选择完整内容校验。
• 发现副本后必须手动选择“跳过匹配文件”或“全部再复制一份”，再点最终确认。不覆盖文件，不会默认勾选跳过。
• 任务保存在 ~/Library/Application Support/LightHarbor/tasks，仅含本机路径、整理计划和校验信息，不上传、不随安装包分享。
• 支持文件级续复制：恢复任务后重新核对并确认；完成的副本可选择跳过，中断的文件需完整重复制，不支持单个文件内部按字节续传。
• 恢复使用原来的来源与目标路径。磁盘离线或来源内容改变时停止并提示。外部移动过的归档副本可能需重新扫描。

1.3.0：导入状态、暂停与完成记录
• 扫描后按日期显示未整理、已有副本、需要核对的文件数，点击数量查看明细。1.3.4 默认显示同名匹配状态，明确标注未核对内容；选择完整内容校验时才读取文件。
• 复制时显示传输量、已处理文件数、平均传输速度和估算剩余时间。速度和时间包含校验等待，实际耗时受磁盘影响。
• “暂停复制”保留本次任务，点击“继续复制”接着处理；“停止”则结束本次执行，下次通过恢复任务重新核对。暂停状态退出也会安全停止。
• 完成页分别展示新复制、确认跳过、失败和未处理数量。展开实际归档目录，可在访达中打开。未连接的磁盘会提示接回。
• 失败照片可以重新核对再复制；关联文件一起核对，已有副本仍须手动确认跳过。
• 新版的历次执行记录保存在本机任务目录的 history 子目录，按拍摄日期或整理日期搜索，支持分页查看全量明细。旧版原始整理记录仍保留在归档目录的 .整理记录 中。

1.3.4：快速查重与校验复用
• 默认仅匹配文件名和扩展名（忽略大小写），发现同名文件后仍须手动确认是否跳过；大小不同会提示。
• 完整校验结果在本次运行中复用，文件身份、大小或修改状态变化后重新校验；重启后不沿用内存缓存。
• 新文件边复制边计算校验值，复制后核对目标文件，减少复制前额外读取来源的次数。

1.3.4 清理存储卡
扫描后点击“清理存储卡”，勾选拍摄日期并完整核对备份。备份必须在另一个磁盘卷。RAW/JPEG/XMP 关联文件全部核验通过后才可清理。未关联文件及视频不清理。
核对后可展开完整清单，输入“删除 N 个文件”确认。确认后再次核对来源与备份；永久删除不经过废纸篓，不能在拾光内撤销。未备份或变化文件保留。清理日志位于本机任务目录旁 cleanup-logs。清理结束后请重新扫描。
