拾光 · LightHarbor 1.5.0
让底片，回到各自的位置。

支持 macOS 13 Ventura 及以上，Apple 芯片 / Intel 通用二进制。已含运行时，无需安装 Python 或开发工具。解压 ZIP，把“拾光.app”放入 Applications 或自己的工具文件夹后打开。支持原生文件夹选择、调整窗口和复制粘贴，⌘R 可重新载入。

本版本为本地临时签名，尚未获得 Apple Developer ID 签名与公证。请保留系统安全保护，确认来自你授权构建的本地版本或官方 GitHub Release 后按系统提示处理首次打开。

整理复制
选择来源与独立保存位置，扫描后直接浏览照片。按日期、拍摄组和照片复选框选择复制范围，照片类型可逐张修正为普通照片或延时摄影，与复制勾选独立；关联文件一起归类，修改后的提示提供撤销。照片信息仅从大图中的“查看信息”打开，不提供改名或拆分。
点击“复制所选”，核对归档去向与重复文件处理，再确认复制。匹配文件必须手动选择跳过或再复制，不会默认跳过、覆盖或删除来源。RAW / JPEG 和可靠关联文件一起处理。支持暂停、继续、失败重试和全量结果明细。

清理照片
可以选择任意照片文件夹，默认直接清理，不强制检查备份。扫描后照片直接可见，勾选照片后仅一次最终删除确认；取消确认保留选择。删除后可继续选择剩余照片，不需手动重新扫描。
最终确认会永久删除所选及可靠关联文件，不经过废纸篓，请自行确认可以删除。视频及未关联文件不纳入照片清理。
可在清理设置中选择“核对备份后清理”，该模式要求另一个磁盘卷上有内容完全一致的完整备份。文件变化会阻止删除，清理日志保存在本机任务目录旁的 cleanup-logs。

整理记录与恢复
整理记录页显示本机历史和恢复入口，不显示无关照片导航。任务保存在 ~/Library/Application Support/LightHarbor/tasks；恢复后重新核对已有副本并确认。正常退出会安全停止活动任务，已完成副本保留。强制结束或断电后请检查结果。

照片只在本机处理，不上传。格式预览取决于系统与相机，预览失败不代表不能复制原文件。延时识别是辅助判断，默认至少 30 次拍摄、20% 间隔容差。新扫描按年 / 拍摄日期归档，不分析地点或景物；当天只有普通照片、延时摄影或视频一种类型时省略类型层，每段延时仍独立归档，跨午夜按日期拆分。旧任务恢复保持原路径。

源码验证使用生成的临时素材：208项回归、独立行为验证和审查及鼠标交互自检；本机替换前另核对安装包完整性与临时素材功能。结构与自检不代表每种Mac或系统均已实测。

日期与照片联动：点击日期只浏览当天；勾选日期只批量选择，不切换当前查看日期，保留其他日期的选择。单张大图可勾选或取消，状态与缩略图和数量同步。扫描显示实际阶段、已扫描文件数和当前文件，总数未定时不显示百分比。

左侧只显示拍摄日期，含延时照片的日期显示延时图标。切换日期恢复全部分类，保留搜索和勾选。

本版新增：侧栏与照片区各有“全选”；照片区全选覆盖当前日期、分类与筛选结果的全部分页。普通照片与延时摄影在照片区切换，延时摄影单独归档。复制默认同时复制 JPG 与 RAW，也可选择仅 JPG或仅 RAW。仅JPG保留可靠归属于JPG的AAE/XMP；仅RAW保留关联XMP；缺少所选格式的拍摄跳过并提示。

大图支持空格选择、左右方向键切换、Esc 或右上角关闭；支持缩放、拖动与适应窗口。缩略图与大图可分别选择低清/高清，RAW 优先读取内嵌预览；高清不足或没有内嵌预览时，尝试通过 macOS Core Image 解码 RAW，按真实像素缩小至最长边3200，不放大小图。仍保留配套 JPG 回退，并标明RAW内嵌预览、RAW解码预览或配套JPG及实际尺寸。系统无法解码时保留可用预览并说明原因。缩略图与大图按方向标签校正旋转及镜像，不重复旋转，不修改原片。相机支持取决于macOS，测试使用生成DNG等临时素材，不代表所有真实相机均已验证。

复制与清理照片列表均提供“显示全部”，展开当前日期、分类和搜索结果，不改变选择。缩略图在滚动接近时读取，避免立即读取全部照片。

设置按实际值判断变化。内容不变时关闭设置会保持照片和选择，改回原值可恢复使用；真实路径或规则变动需重新扫描后复制。

本版优化：单张勾选不重建其他照片；清晰度菜单每次选完（含重复选择同档）释放焦点。照片信息随大图翻页同步，同张照片的文件明细保持展开和滚动，新照片默认收起。重复文件选项为整行选择，必须明确选择后才能复制。

1.5.0 七项整合优化
Mac系统窗口支持一次多选多个来源文件夹；来源列表支持添加、移除，重叠目录只扫描一次，重扫保留未变化照片的勾选与类型修正。来源身份隔离，避免同名照片配错关联文件或误合并序列。照片信息显示来源。
视频独立归档；JPG / RAW分开存放默认开启并记住选择，关闭后混放，与复制格式范围独立。完整扫描决定单类型省层级，不随分批勾选改变。已有归档布局及同一延时序列目录复用，不自动迁移旧文件。
复制前核对文件内容及本批次重复，必须明确选择跳过匹配文件或再复制一份；同名不同内容整组安全编号，不覆盖。完成后显示实际结果，可打开目标文件夹或继续选择下一批；继续时清空勾选但保留浏览和设置，每批独立保留结果，再次复制仍需预览确认。
Mac与Windows采用统一产品版本号，但平台交付和验证分别记录。本次仅本机Mac1.5.0；Windows1.5.0尚未打包交付，Windows原生验证仍待完成。
