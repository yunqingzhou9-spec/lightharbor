拾光 · LightHarbor 1.3.13
让底片，回到各自的位置。

支持 macOS 13 Ventura 及以上，Apple 芯片 / Intel 通用二进制。已含运行时，无需安装 Python 或开发工具。解压 ZIP，把“拾光.app”放入 Applications 或自己的工具文件夹后打开。支持原生文件夹选择、调整窗口和复制粘贴，⌘R 可重新载入。

本版本为本地临时签名，尚未获得 Apple Developer ID 签名与公证。请保留系统安全保护，确认来自官方 GitHub Release 后按系统提示处理首次打开。

整理复制
选择来源与独立保存位置，扫描后直接浏览照片。按日期、拍摄组和照片复选框选择复制范围，可改名、合并、拆分、移组、抽样、筛选与撤销。信息与调整集中在一个入口。
点击“复制所选”，核对归档去向与重复文件处理，再确认复制。匹配文件必须手动选择跳过或再复制，不会默认跳过、覆盖或删除来源。RAW / JPEG 和可靠关联文件一起处理。支持暂停、继续、失败重试和全量结果明细。

清理照片
可以选择任意照片文件夹，默认直接清理，不强制检查备份。扫描后照片直接可见，勾选照片后仅一次最终删除确认；取消确认保留选择。删除后可继续选择剩余照片，不需手动重新扫描。
最终确认会永久删除所选及可靠关联文件，不经过废纸篓，请自行确认可以删除。视频及未关联文件不纳入照片清理。
可在清理设置中选择“核对备份后清理”，该模式要求另一个磁盘卷上有内容完全一致的完整备份。文件变化会阻止删除，清理日志保存在本机任务目录旁的 cleanup-logs。

整理记录与恢复
整理记录页显示本机历史和恢复入口，不显示无关照片导航。任务保存在 ~/Library/Application Support/LightHarbor/tasks；恢复后重新核对已有副本并确认。正常退出会安全停止活动任务，已完成副本保留。强制结束或断电后请检查结果。

照片只在本机处理，不上传。格式预览取决于系统与相机，预览失败不代表不能复制原文件。延时识别是辅助判断，默认至少 30 次拍摄、20% 间隔容差。GPS 为坐标分区而非城市，景物分类由 Apple Vision 提供。

本次验证使用临时素材：128 项回归、真实复制/恢复/清理、独立行为与代码审查、打包恢复及文件一致性通过。本机原生复制来源、保存位置和清理目录选择已验证。通用架构是构建目标，不代表每种 Mac 与系统均已实测。
