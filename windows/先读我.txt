拾光 LightHarbor · Windows 1.5.0 x64 便携预览版
与 Mac 1.5.0 共用版本和整理逻辑，保留 Windows 照片方向与 RAW 高清预览修正。本包尚未在 Windows 实机验证。

启动
1. 适用于 Windows 10/11 x64（Intel/AMD），不是 Windows ARM 原生版。
2. 完整解压 ZIP 到本机文件夹，不要直接在压缩包中运行。
3. 双击 Start-LightHarbor.cmd，稍候将出现独立窗口；后台命令窗口请保留。
4. 通过拾光窗口正常退出；复制期间不要直接关闭后台命令窗口。
已含 Python 和程序依赖，无需另装 Python，不要求管理员权限。

系统组件
需要 Microsoft Edge WebView2 Runtime 和 .NET Framework 4.8。若缺少组件，请从微软官方安装：
https://developer.microsoft.com/microsoft-edge/webview2/
https://dotnet.microsoft.com/download/dotnet-framework/net48
本包不静默安装组件，不关闭或绕过系统安全保护。它不是已签名的正式安装器。
启动失败日志：%LOCALAPPDATA%\LightHarbor\startup-error.txt
任务与恢复记录：%LOCALAPPDATA%\LightHarbor\tasks

1.5.0 整理优化
• 整理复制可添加多个来源文件夹，父子目录去重；同名照片按来源目录隔离配对。增删后重新扫描，未变化照片保留选择与类型修正。
• Windows 继续使用自定义目录缩略图选择窗口。来源支持多选、增删和确认；保存位置及清理仍选一个文件夹。
• 视频独立归档；JPG / RAW 可分开存放。当天只有一种拍摄类型时省略类型目录，已有归档结构不搬动。
• 复制完成后显示结果，可继续分批选择；已复制照片退出当前选择，未选择的照片可继续选择。
• 同一任务分批复制复用归档目录和延时序列目录；历史布局保持稳定。已有副本按内容核对，并要求明确选择跳过或再复制，不覆盖文件。
• Mac、Windows 产品版本统一为1.5.0；Windows原生验证状态单独记录，仍为预览版。

目录缩略图选择窗口
• 来源、保存位置及清理来源均使用独立的目录窗口。显示子文件夹、照片缩略图和文件名；点文件夹进入，支持上一级、磁盘、个人文件夹和输入路径（含共享路径）。
• 照片文件只供查看，单选时确认当前目录；多选来源时将多个目录加入列表后确认。扫描包含子目录；取消不改变已选路径。空文件夹也可作为保存位置。此窗口不创建、修改或删除任何文件。
• 每页120项，缩略图仅在接近可见范围时加载，最多两路并发。XMP是附属信息文件，没有独立照片缩略图。
• 本版扩大的是预览解码范围；扫描所识别的照片后缀与1.4.4一致（包含CR2/CR3/NEF/NRW/ARW/RAF/DNG/ORF/RW2/PEF/SRW）。其他少见RAW即使可在目录窗口预览，也未新增到扫描照片分类。

本版交互
• 左侧日期文字只浏览，复选框只选择，跨日期勾选保留。切换日期恢复全部分类，含延时照片的日期带图标。
• 左侧全选覆盖所有日期；照片区全选覆盖当前日期、分类和搜索结果，包括未加载分页。
• 单张勾选不重建其他照片，保留图片、滚动和位置。
• 复制格式提供 JPG+RAW（默认）、仅JPG、仅RAW。仅JPG携带可靠归属于JPG的AAE/XMP；仅RAW保留关联XMP；缺少对应格式的拍摄跳过并提示。
• 类型在每张照片的菜单里修正，与复制勾选独立；RAW/JPG关联一起归类，不修改原件。按日期和原分组保留延时序列，结果提示可撤销。不提供改名或拆分。
• 大图空格选择、左右翻页、Esc关闭，支持缩放拖动。缩略图与大图分别选择低清/高清，选完（含重复选同档）释放焦点。
• “查看信息”只在大图里。文件明细在同一照片中保持展开和滚动；翻到另一张默认收起。
• 重复文件处理为两条整行选择：跳过匹配文件，或全部再复制一份。必须明确选择后才能复制；不覆盖已有文件，不删除来源。
• 清理可选任意照片目录，默认直接清理。最后一次确认会永久删除所选照片及关联文件，不经过废纸篓；取消保留选择。请先确认可删除。
• 可在清理设置选择“核对备份后清理”，要求独立磁盘卷上的内容一致副本。删除日志在任务目录旁的 cleanup-logs。

Windows 差异与验证范围
这是预览包。已核对运行时/依赖哈希、包内文件和当前共享源码；已在 Mac 用生成的临时素材检查共享逻辑和 Windows 媒体读取逻辑。这不等同 Windows 原生运行验证。
独立窗口、WebView2/.NET集成、目录选择桥接、Windows卷识别及真实Windows路径/权限、独立目录窗口与主窗口关闭行为仍需实机试用。
请先用临时测试素材验证复制与恢复，再处理重要照片；清理功能请格外谨慎。
不支持 Mac Vision 景物识别。RAW低清优先读取内嵌预览，缺失时通过rawpy/LibRaw进行半尺寸解码回退；高清优先尝试大尺寸内嵌预览，不足时尝试原尺寸RAW解码，再按实际像素缩小至最长边3200，不放大小图；HEIC/HEIF使用pi-heif解码。解码在本机进行，不修改照片。RAW原生解码在独立子进程执行，最多两路并发、单次25秒；不支持、损坏或超时显示暂无预览，原文件仍可扫描和复制。
不同相机型号、压缩方式和新格式存在差异，不保证所有照片都有缩略图；JXL等未内置解码的格式显示格式图标。RAW高清仍按实际预览尺寸显示，不补造细节。解码失败或超时保留可用内嵌预览并说明原因；大图标明RAW内嵌预览、RAW解码预览或配套JPG及实际尺寸。
方向统一在预览像素中校正一次，涵盖旋转与镜像。内嵌图片自身的明确方向优先，其次为对应缩略图标签、RAW原文件方向；原生解码关闭自动旋转后统一校正，避免重复旋转。缺失或互相矛盾的相机元数据仍需具体样本确认。
高清来源与实际尺寸会显示；不把低分辨率图片冒充高清。已使用生成的DNG、带JPEG预览的合成CR2容器及损坏素材检查，未测试朋友的真实相机CR2或所有机型。
目标名称须符合Windows规则，建议使用较短归档路径。
